# RC카 학습·검증용 지도 묶음 (2026-11-24, 시험 지도 제외)

공식(공개) 트랙이 아닌, 우리 팀이 생성한 소형 트랙 지도입니다. **학습(train)과 검증(val)에만** 쓰도록 만든 묶음이며, 시험(test)용 지도는 하나도 들어 있지 않습니다.

## 구성 (총 580개)

| 폴더 | 그룹 | 개수 | 설명 |
|---|---|---|---|
| train/ | compact_train | 240 | 대회장 크기(약 8×22 m)의 격자형 소형 트랙, 최소 폭 약 1 m |
| train/ | sketch_train | 120 | 대회 공지 스케치(8자 비슷한 루프)를 닮은 곡선형 트랙 |
| train/ | ga75_hard_train / ga77_hard_train | 60 / 60 | 우리 정책이 어려워한 형상을 유전 알고리즘으로 찾은 지도(난이도 높음) |
| val/ | compact_val | 30 | compact 검증용 |
| val/ | sketch_val | 20 | sketch 검증용 |
| val/ | dev2_val | 50 | 늦게 만든 추가 검증용(compact 30 + sketch 20) |

`gallery/*.png`에서 그룹별 모양을 한눈에 볼 수 있습니다.

## 지도 폴더 형식 (지도마다 같음)
- `<이름>_map.png` + `<이름>_map.yaml`: 해상도 0.05 m/px의 점유 지도(ROS map_server 형식, yaml의 image는 상대 경로)
- `<이름>_centerline.csv`: `x_m, y_m, w_right_m, w_left_m` (중심선과 좌우 폭)
- 시뮬레이터의 `installation/maps/<이름>/`에 폴더째 복사하면 기존 지도와 같은 방식으로 불러올 수 있습니다.

## 쓸 때 주의
- **검증(val) 지도로 학습하지 마세요.** 검증 성능이 실제보다 좋게 나옵니다.
- 시험 지도(별도 보관, 미포함)와 같은 중심선을 가진 지도는 제외 검사를 했습니다(해당 0개).
- 일부 GA 지도(3개)는 compact_train 지도와 중심선이 같고 폭만 다릅니다.
- `manifest.json`에 지도별 파일 SHA256과 그룹이 있습니다.
